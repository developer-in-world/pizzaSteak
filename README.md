# 🍕 Pizza vs Steak Classifier

A Computer Vision application built using **PyTorch** and **Gradio**.

## Features

- CNN built from scratch
- Image Classification
- Web Interface
- Deployable on Hugging Face Spaces

## Tech Stack

- PyTorch
- TorchVision
- Gradio
- Pillow

## Run Locally

```bash
pip install -r requirements.txt
python app.py
```

## Demo

Upload a Pizza or Steak image and the model predicts the class with confidence.
